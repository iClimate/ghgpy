# About GHGPy

## Project Overview

GHGPy is an open-source Python package for greenhouse gas (GHG) inventory calculations, designed to make carbon accounting accessible and accurate.

**Carbon inventory, make it easy!**

## Mission

To provide a comprehensive, easy-to-use tool for organizations to track, calculate, and report their greenhouse gas emissions following international standards.

## Features

- **IPCC Compliant** - Based on IPCC 2006 Guidelines with 2019 Refinements
- **Multi-Sector Support** - Energy, IPPU, AFOLU, and Waste sectors
- **Uncertainty Tracking** - Built-in uncertainty data types
- **Flexible Database** - Excel, SQLite, and MySQL support
- **Factory Pattern** - Easy-to-use facility-level tracking
- **Open Source** - MIT licensed, community-driven

## Methodology

GHGPy follows the IPCC Guidelines for National Greenhouse Gas Inventories:

- **Tier 1** - Default emission factors
- **Tier 2** - Country-specific factors
- **Tier 3** - Facility-specific data
